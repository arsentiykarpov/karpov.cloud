>> В 2013 году присоединился вторым участником в состав команды Android разработки Киви, где начал разрабатывать первые версии Киви Кошелька. 

>> С 2016 стал "играющим" тимлидом Android команды Киви.

> **Сервис бесконтактной оплаты Visa payWave**
>> Реализовал внутри Киви Кошелька функционал бесконтактной оплаты Visa PayWave	при помощи технологии Host Card Emulation без использования Visa SDK, с 0 реализовал протокол [телефон] <---> [POS терминал].  В приложении можно было выпускать токенизированную карту и платить телефоном по  NFC через POS терминал. Первое решение на Российском рынке на тот момент. 

> **Совесть. Карта рассрочки.**
>> Разработал первую версию приложения карты рассрочки Совесть.
>> Далее Совесть отделилась в  новое АО со своей группой разработки.

> **Qiwi Инвестор**
>> Разработал первую версию кроссплатформенного приложения для инвестиций Киви Инвестор. В качестве кроссплатформенной библиотеки использовали J2ObjC.
