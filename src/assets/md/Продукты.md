- Киви Кошелек
	В 2013 году присоединился вторым участником в состав команды андроид разработки Киви, где начал разрабатывать первые версии Киви Кошелька. 
	С 2016 стал "играющим" тимлидом андроид команды Киви.
- Сервис бесконтактной оплаты
	Реализовал внутри Киви Кошелька функционал бесконтактной оплаты Visa PayWave
	при помощи технологии Host Card Emulation без использования Visa SDK, с 0 реализовал протокол [телефон] <---> [POS терминал].  В приложении можно было выпускать токенизированную карту и платить телефоном через  POS терминал. Первое решение на Российском рынке на тот момент. 
- Совесть. Карта рассрочки.
	Разработал первую версию приложения карты рассрочки Совесть. Далее Совесть отделилась в  новое АО со своей группой разработки.
- Киви Инвестор
	Разработал первую версию кроссплатформенного приложения для инвестиций Киви Инвестор. В качестве кроссплатформенной библиотеки использовали J2ObjC. 
- Ферма устройств
	Интегрировал ферму устройств в процессы CI/CD. О чем рассказал на конференции [Qiwi Android Developer Days](https://www.youtube.com/watch?v=_DBV36UJBaI)
- Платформа Чата поддержки c SDK и кроссплатформеностью.
- Цифровой Рубль
	Разработал первую версию кроссплатформенного проекта Цифрового Рубля. В качестве кроссплатформенной библиотеки использовали Kotlin Multiplatform.
